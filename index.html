// glisse-moi vers ta barre de favoris 🏦 Télécharger mes relevés

Installation

1

Affiche ta barre de favoris : Ctrl + Maj + B.

2

Glisse le bouton ci-dessus vers ta barre de favoris, puis relâche.

3

Connecte-toi à Boursobank, va sur Documents > Relevés.

4

Autorise les téléchargements multiples si le navigateur le demande.

5

Clique sur le favori. Les relevés arrivent les uns après les autres.

Pourquoi glisser et pas cliquer ? Chrome n'ajoute pas un bookmarklet depuis un fichier téléchargé. Le glisser-déposer du bouton vers la barre de favoris est la seule méthode fiable.

Sinon, méthode console : sur la page des relevés, ouvre F12, colle le contenu de boursobank-bulk-statement-downloader.js, puis Entrée.
