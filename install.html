Téléchargeur de relevés Boursobank en lot

Télécharge d'un coup tous tes relevés PDF depuis ton compte Boursobank, au lieu de cliquer sur chacun à la main.

Installation (glisser-déposer) :

🏦 Télécharger mes relevés

Comment installer le bouton ci-dessus :

  1. Affiche ta barre de favoris dans Chrome : Ctrl + Maj + B.
  2. Glisse le bouton rose vers ta barre de favoris, puis relâche.
  3. Connecte-toi à Boursobank et va sur Documents > Relevés.
  4. Autorise les téléchargements multiples si le navigateur le demande.
  5. Clique sur le favori. Les relevés se téléchargent les uns après les autres (1,5 s entre chaque).

Le glisser-déposer est la seule méthode fiable : Chrome ne permet pas d'ajouter un bookmarklet en téléchargeant un fichier.

Sinon, méthode console : sur la page des relevés, ouvre la console (F12), colle le contenu de boursobank-bulk-statement-downloader.js, Entrée.
